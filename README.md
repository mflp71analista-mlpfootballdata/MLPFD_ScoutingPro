MLPFootballData es una aplicación web interactiva desarrollada en Python y Streamlit orientada a la identificación y análisis comparativo de futbolistas. La herramienta permite a directores deportivos, analistas y secretarías técnicas encontrar sustitutos o perfiles similares a un Jugador Modelo de referencia, aplicando algoritmos de distancia e índice de coincidencia estadística sobre métricas por 90 minutos
